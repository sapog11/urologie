## 🎯 Краткая инструкция

### На этой неделе (ОБЯЗАТЕЛЬНО):

```bash
1. Google Search Console
   → https://search.google.com/search-console
   → Добавить https://mencare.cz
   → Подтвердить (метатег)
   → Отправить https://mencare.cz/sitemap.xml

2. Яндекс.Вебмастер
   → https://webmaster.yandex.ru/
   → Добавить https://mencare.cz
   → Подтвердить (метатег)
   → Отправить https://mencare.cz/sitemap-yandex.xml

3. Google My Business
   → https://www.google.com/business/
   → Создать профиль MenCare clinic
   → Добавить адрес, телефон, фото
```
