## ⚠️ Первое, что нужно знать

**В этой папке есть несохранённая в git работа.** Ветка `snapshot/live-site-2026-08-27`,
последний коммит от 28.08.2026, а поверх него — 14 изменённых файлов: весь сентябрь
(тексты «приватная урологическая амбулатория», SEO, блок ближайшей записи, прайс, адрес).

Эти правки **уже работают на mencare.cz**, но в GitHub их нет. Значит:

- копировать папку нужно целиком, а не клонировать репозиторий — иначе потеряешь месяц работы;
- на новом компьютере не делай `git checkout .`, `git reset --hard`, `git stash` — сотрёшь несохранённое;
- когда дойдут руки — закоммить: `git add -A && git commit -m "Сентябрь: амбулатория, SEO, ближайшая запись"`.

**Секрет на диске.** В `functions/.env` лежат почтовый логин и пароль для формы записи.
Файл в `.gitignore`, в GitHub его нет — и правильно. Но на внешнем диске он есть: не оставляй
диск где попало и не заливай папку в облако целиком.

## Как работать на новом компьютере

### Что поставить

```
Node.js 20+           https://nodejs.org
Firebase CLI          npm install -g firebase-tools
```

### Вход в Firebase

```
firebase login
```

Аккаунт — тот же, под которым заведён проект `urologie-9b2bf` (mobilezoryx@gmail.com).

### Посмотреть локально

Сборки нет, подойдёт любой статический сервер из папки проекта:

```
npx serve .
```

Откроется на `http://localhost:3000`. Важно: с `file://` работать не будет — блок
«ближайшая запись» ходит в API и упрётся в CORS.

### Выложить на сайт

```
firebase deploy --only hosting
```

Полторы минуты — и правки на mencare.cz. Откат, если что-то сломал: в консоли Firebase →
Hosting → история версий → «Откатить».

Облачные функции (форма записи) деплоятся отдельно и трогать их обычно не нужно:

```
cd functions && npm install
firebase deploy --only functions
```

## Связь с ZORYX

Запись на приём работает через платформу ZORYX (отдельный проект, `D:\zoryx-app`).

**Виджет записи** — iframe, открывается в модальном окне по любой кнопке записи:

```
https://zoryx.app/clinic/embed/AAA_mencare_clinic?lang=ru
```

**Блок «Ближайшая запись»** (`js/next-slot.js`) при загрузке страницы спрашивает у ZORYX
ближайший свободный слот:

```
https://zoryx.app/api/schedules?mode=next&clinicId=AAA_mencare_clinic
```

Ответ вида `{date, time, doctorId}` превращается в строку «Ближайшая запись: 27 августа в 15:20».
Клик открывает виджет сразу на этом слоте: `?date=…&doctor=…&time=…`.

Если ZORYX недоступен или слотов нет — блок просто не показывается. Сайт от этого не ломается,
остальные кнопки записи работают как обычно.

`AAA_mencare_clinic` — идентификатор амбулатории в ZORYX, менять его нельзя.

## Если что-то сломалось

**Правки не видны на сайте** — очисти кэш браузера (Ctrl+Shift+R). Firebase отдаёт новую
версию сразу, а браузер держит старый CSS.

**Блок «Ближайшая запись» пропал** — проверь ответ API:
`https://zoryx.app/api/schedules?mode=next&clinicId=AAA_mencare_clinic`.
Пустой `date` означает, что в ZORYX нет расписаний или свободных слотов.

**Форма записи не отправляет письма** — смотри логи функций: `firebase functions:log`.
Скорее всего дело в `functions/.env`.

**Съехала вёрстка на узком экране** — почти всегда `css/responsive.css`. Расстояние между
заголовком и подзаголовком на первом экране завязано на переменную `--hero-gap`: она меняется
по брейкпоинтам, и подзаголовок считает отступ от неё. Жёсткие отрицательные отступы туда
лучше не возвращать — именно из-за такого текст наползал на заголовок.
